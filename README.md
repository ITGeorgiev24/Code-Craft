<h2 id="about-the-project">About The Project</h2>
    
<p align="justify">
MAZEBOUND is a console maze game in C++ for Visual Studio 2026, built on a
three-layer architecture – three separate projects: UI → Logic → Data.
Start in the top-left corner and find the exit in the bottom-right corner.
Every game is a brand-new random maze. Every player has an account that keeps the campaign
progress and the name on the leaderboard.
</p>

## Accounts

The game starts with a login screen:

* **Log in** – username and password (the password is shown as `*****`), or **Back**.
* **Create account** – a username (3–16 latin letters, digits, `_ - .`) and a password (4–20
  characters, typed twice).
* **Log out** in the main menu goes back to the login screen.
* Every menu and form has a **Back** button (Esc works the same way).


The accounts are saved in the text file **`mazeboundAccounts.txt`** – one line per player:

```
Ivan;-1962825348;2;3;0;0;0;0;0;0;0;0;0;450;0;0;0;0;0;0;0;0;0
```

username; the password hash; unlocked levels; best stars of the 10 levels; best scores of the 10 levels.
The password itself is **not** saved – only a number made from it (a *hash*). When the player logs in,
the number of the typed password is compared with the saved one.

## Game modes

| Mode | Description |
|------|-------------|
| **Campaign** | 10 levels from 10×10 Easy to 50×50 Expert. Winning a level unlocks the next one. Every level gives 1–3 stars. |
| **New game** | Choose the difficulty and the size (10–50). A new random maze is created. |
| **Quick game** | A new random maze with the last chosen size and difficulty. |
| **Daily challenge** | Always the same 25×25 Normal maze – everybody plays the same maze and can compare results. |

## Difficulty levels

| Difficulty | Loops (other ways) | Keys | Compasses | Visibility | Score × |
|------------|-------------------|------|-----------|------------|---------|
| **Easy**   | many (10 %) | one more than doors | 2 | whole maze | ×1 |
| **Normal** | a few (4 %) | one per door        | 1 | whole maze | ×2 |
| **Hard**   | none – only one way | one less than doors | 0 | whole maze | ×3 |
| **Expert** | none – only one way | one less than doors | 1 | **fog** `~~` – only what you explored | ×4 |

## Symbols

| Symbol | Meaning | Symbol | Meaning |
|--------|---------|--------|---------|
| `@` | you | `k` | key – opens one door |
| `##` | wall | `$` | coin – +25 points |
| `[]` | secret door (shortcut) | `c` | compass – one free hint |
| `EX` | exit (green letters) | `*` | hint – the next steps of the shortest way |
| `.` | your trail | `~~` | fog (Expert) |
| `->` | entrance / way out | `::` | the maze continues (camera) |

## Keys

| Key | Action |
|-----|--------|
| Arrow keys / `W A S D` | move |
| `H` | hint (free with a compass, otherwise −25 points) |
| `I` | information about your place |
| `L` | legend |
| `M` | full map / camera view |
| `R` | restart the same maze |
| `?` | help |
| `Q` / `Esc` | back to the menu |


## Architecture – three layers, three projects

```
 MAZEBOUND.UI  ────────────►  MAZEBOUND.Logic  ────────►  MAZEBOUND.Data
 application (.exe)           static library              static library
 main.cpp, menus,             rules, maze generation,     structures, dynamic
 input, drawing               BFS, campaign, score        arrays, files
                                      ▲
               MAZEBOUND.Tests ───────┘  (tests the Logic and Data layers)
```
